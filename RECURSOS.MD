# Recursos utilizados

## Archivos necesarios para ejecutar el programa

Este proyecto **no requiere archivos adicionales** para ejecutarse. El
programa fue construido usando únicamente el módulo estándar de Python
(sin librerías externas, sin bases de datos, sin archivos de configuración
ni recursos gráficos), por lo tanto basta con:

- Tener Python 3.8 o superior instalado.
- El archivo `Cudricula_Circulos.py` de este repositorio.

## Herramientas de desarrollo

- **Python 3**: lenguaje de programación utilizado para todo el desarrollo.
- **Visual Studio Code**: editor utilizado para escribir y probar el código.
- **GitHub**: plataforma utilizada para el control de versiones y la
  entrega del repositorio (GitHub Education).

## Uso de inteligencia artificial

Se utilizó Claude (Anthropic) como apoyo para comprender la lógica de
manejo de matrices en Python, la validación de coordenadas y la
estructura de un menú interactivo por consola. La herramienta no generó
la documentación final del análisis ni las conclusiones del proyecto;
estas fueron redactadas por el autor con base en la comprensión guiada
del código.

escala]. https://claude.ai
